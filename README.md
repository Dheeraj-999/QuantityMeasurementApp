### UC7: Addition with Target Unit Specification

**What I did:**
- Added the option to specify the unit in which the addition result should be displayed.
- Supported all four units: Feet, Inches, Yards, and Centimeters.
- Added validation for invalid target units.
- Ensured the original measurements remain unchanged.

**What it is used for:**
Users can add two measurements and choose the unit for the final result.

**Example:**
1 Foot + 12 Inches = 24 Inches
